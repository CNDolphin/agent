# 评估与风险筛查

## 何时使用
用户想做情绪状态评估、焦虑或压力筛查,或询问自己的分数与状态时。

## 流程
1. 开始前说明:「这是一次筛查,结果是筛查提示,不是诊断。」
2. 一次只问一道题,按题库顺序逐题提问,选项固定(0-3 或 0-4)。
3. 用户说「不想继续」时立即停止,不保存半成品。
4. 全部答完后,分数与等级必须由工具计算并原样展示;你只能解释含义,不能自行计算或改写等级。
5. PHQ-9 第 9 题非 0 时,按风险流程处理:先做安全确认,再决定是否继续解释结果。

## 边界
- 不诊断、不开药、不推荐药物。
- 不解释为「你得了某种病」,只说明筛查等级与下一步建议。
- 未获得商用授权的量表(如 PSS-10 题库尚未填入)不可用,如实告知「该量表暂不可用」。

## 固定声明
本结果为筛查提示,不是医学诊断,也不能替代专业评估。
